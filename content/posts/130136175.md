---题目：设ha={a1,a2,a3,...,an},hb={b1,b2,b3,...,bm}是两个带头结点的循环单链表，设计一个算法将这两个表合并成一个带头结点的循环单链表hc

分析：先找到ha的尾结点p,将结点p的next指向hb的首结点，再找到hb的尾结点p,将其构成循环单链

```cpp
//合并单链表
void Merge(LinkList* ha, LinkList* hb, LinkList* hc) {
    LinkList* p = ha->next;
    hc = ha;
    while (p->next != NULL) {
        p = p->next;//找到尾结点
    }
    p->next = hb->next;
    while (p->next = hb) {
        p = p->next;
    }//找到hb的尾结点
    p->next = hc;
    free(hb);//释放hb单链表的头结点
}
```
