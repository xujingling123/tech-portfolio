---知识点：

**回文数：**实际上就是倒着读和正着读都一样的数，如12321,正读和倒读都是一样的,这就是回文数,也叫做逆序数

代码：

```cpp
//求回文数

#include <stdio.h>
#include <stdlib.h>
int fun(int n)
{
    int i = 1, m = 0, k, a = 0;
    //这里的while循环是产生1~n之间的数字
    while (i < n)
    {
        k = i;
        m = 0;
        //内层while循环才是真正实现逆序数的方法
        //这里采用的是逆序数的方法：比如：121，通过下面的方法（（1*10+2）*10）+1=121
        while (k > 0)
        {
            m *= 10;
//2.将原来个位上的数*10；3.将原来（个位上的数*10+十位上的数）*10
            m += k % 10;
//1.得到个位上的数；2.得到十位上的数+原来个位上的数*10；3.得到百位上的数+（个位上的数*10+十位上的数）*10
            k = k / 10;
//1.除以10，去掉个位上的数；2.去掉十位上的数；
            //后面继续重复上述操作，直到将所有的数都处理完
        }
        //如果此时的m等于i的话，就是回文数
        if (m == i)
            printf("%d是回文数\n", i);
        i++;
    }

}

int main()
{
    int n;
    printf("请输入回文数的范围：");
    scanf("%d", &n);
    fun(n);
    return 0;
}
```
