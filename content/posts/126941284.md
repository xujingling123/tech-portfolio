---编写代码实现，模拟用户登录情景，并且只能登录三次。（只允许输入三次密码，如果密码正确则提示登录成功，如果三次均输入错误，则退出程序）

**代码截图：**

![](https://i-blog.csdnimg.cn/blog_migrate/21562d199003695a32f7ac87ea1e23e3.png)

 **代码：**

//编写代码实现，模拟用户登录情景，并且只能登录三次。（只允许输入三次密码，  
// 如果密码正确则提示登录成功，如果三次均输入错误，则退出程序  
#include <string.h>  
int main() {  
    char arr\[\] = "1234567";  
    char password\[10\] = "";  
    int i = 0;  
    for (i = 0; i < 3; ++i)  
    {  
        printf("请输入密码--》：");  
        scanf("%s", password);  
        if (strcmp(password, arr) == 0) {  
            printf("登录成功！");  
            break;  
        }

    }  
    if (i == 3)  
    {  
        printf("3次机会已经用完了，已退出程序！！！");  
    }  
      
}
