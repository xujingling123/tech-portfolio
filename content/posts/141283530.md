---### 描述

给定两个字符串str1和str2,输出两个字符串的最长公共子串

题目保证str1和str2的最长公共子串存在且唯一。 

数据范围： 1≤∣str1∣,∣str2∣≤5000  
要求： 空间复杂度 O(n2)，时间复杂度 O(n2)

### 示例1

输入：

"1AB2345CD","12345EF"

返回值：

"2345"

### 思路分析：

定义**dp\[i\]\[j\]表示字符串str1中第i个字符和str2种第j个字符为最后一个元素所构成的最长公共子串**。如果要求dp\[i\]\[j\]，也就是str1的第i个字符和str2的第j个字符为最后一个元素所构成的最长公共子串，我们首先需要判断这两个字符是否相等。

*   如果不相等，那么他们就不能构成公共子串，也就是  
    **dp\[i\]\[j\]=0;**
    
*   如果相等，我们还需要计算前面相等字符的个数，其实就是dp\[i-1\]\[j-1\]，所以  
    **dp\[i\]\[j\]=dp\[i-1\]\[j-1\]+1**;
    

### 代码：

```java
import java.util.*;


public class Solution {
    /**
     * longest common substring
     * @param str1 string字符串 the string
     * @param str2 string字符串 the string
     * @return string字符串
     */
    public String LCS (String str1, String str2) {
        int maxLen=0;//记录最长公共子串的长度
        int maxLastIndex=0;//记录最长公共子串最后一个元素在字符串str1的位置
        int[][] dp=new int[str1.length()+1][str2.length()+1];
        for(int i=0;i<str1.length();i++){
            for(int j=0;j<str2.length();j++){
                //两个字符相等
                if(str1.charAt(i)==str2.charAt(j)){
                    dp[i+1][j+1]=dp[i][j]+1;//记录长度

                    //记录最长子串最后一个元素的位置
                    if(dp[i+1][j+1]>maxLen){
                        maxLen=dp[i+1][j+1];
                        maxLastIndex=i;
                    }

                }else{
                    //字符不相等
                    dp[i+1][j+1]=0;
                }
            }
        }
        //截取字符串
        return str1.substring(maxLastIndex-maxLen+1,maxLastIndex+1);
    }
}
```
