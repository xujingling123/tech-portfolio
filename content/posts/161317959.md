---### 1\. 适用场景

同一套农场能力，将渲染引擎从 高德 JS API 换为 Mapbox GL JS v3，保留：

*   天地图 + Mapbox 卫星分层底图
*   地块 GeoJSON 图层、设备 HTML Marker、手绘、选址、删除、长按调点

主组件：`components/mapbox/mapbox.vue`  
选址页：`components/poiMapbox/poiMapbox.vue`（农场地址选择）

### 2\. 架构：仍是 renderjs，换的是「地图内核」

与高德版相同的 prop 桥 + callMethod + $emit，renderjs 内改为：

```javascript
import mapboxgl from 'mapbox-gl'

mapboxMap = new mapboxgl.Map({ container: 'container', style: { version: 8, sources, layers } })
```

样式表从 CDN 引入：

```javascript
@import url('https://api.mapbox.com/mapbox-gl-js/v2.15.0/mapbox-gl.css');
```

逻辑层职责不变：坐标转换、`polygonData` 转 GCJ02、Toast、业务提交。
