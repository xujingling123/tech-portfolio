---### 一.环境搭建：

1.安装node：

进入网站，下载对应版本的node.js

[Index of /dist/ (nodejs.org)](https://nodejs.org/dist/ "Index of /dist/ (nodejs.org)")

我这里下载的是：

![](https://i-blog.csdnimg.cn/direct/4c55f5363b634561a93ab3bba41246ba.png)

解压到对应的目录下：

并新建两个文件夹node\_cache和node\_global：

![](https://i-blog.csdnimg.cn/direct/2b67335feacf48bb8693f5863bc23bae.png)

2.配置环境：

打开高级设置，配置你目录下的node：

![](https://i-blog.csdnimg.cn/direct/b890a7b4f2f34ac287a5c18297b6ed0b.png)

3.设置npm全局装包保存路径  
打开命令行工具，运行命令：

> npm config set prefix “D:\\fairy\\app\\node-v16.14.0-win-x64\\node\_global”

> npm config set cache "D:\\fairy\\app\\node-v16.14.0-win-x64\\node\_cache"

4.检查node和npm的版本：

如果出现版本，则安装成功：

![](https://i-blog.csdnimg.cn/direct/cb382efcb6b54fc9a91099a112026ced.png)

### 二.使用脚手架建立一个vue项目

**1.全局安装Vue CLI**：

> npm install -g @vue/cli

安装成功后：

输入：

> vue --version

出现版本号，则安装成功

![](https://i-blog.csdnimg.cn/direct/0e1b1026d5ff48dbb60c81f6f1c6f746.png)

2.使用Vue CLI创建一个新的Vue项目

> vue create vue01

根据你的需要去选择对应的：

![](https://i-blog.csdnimg.cn/direct/df359574f29145a8a098aeb1b905e380.png)

![](https://i-blog.csdnimg.cn/direct/0f0e1d3a5fb344ddaa206a10dee6a924.png)

3.启动开发服务器

> cd vue01  
> npm run serve

![](https://i-blog.csdnimg.cn/direct/bbfc54bf64f0475aa0f18689e98fafa5.png)

打开浏览器并访问 `http://localhost:8080/`

![](https://i-blog.csdnimg.cn/direct/e000a636cbe84c5eb8c4df0a788e85b1.png)
