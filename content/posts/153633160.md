---### 项目概述与技术架构

”小羊咩咩“网站是一个使用纯CSS实现网页动态效果的现代化单页应用，展现了现代Web开发中CSS动画和交互设计的强大能力。

### 技术栈组成

> \- 前端框架 ：Bootstrap 5.0  
> \- 样式语言 ：CSS3（含CSS变量、动画、变换等）  
> \- 布局技术 ：Flexbox + CSS Grid  
> \- 响应式设计 ：媒体查询 + Bootstrap栅格系统  
> \- 交互效果 ：CSS Hover动画 + 3D变换

### 设计理念

项目采用深色主题设计，以紫色系为主色调。整个网站强调视觉冲击力和交互体验，通过CSS动画实现流畅的用户体验。

##### 代码逻辑：

导航栏使用了 Bootstrap 5 的`navbar`组件，核心依赖包括：

*   Bootstrap 5 CSS 框架（已通过`<link href="./bootstrap/bootstrap/bootstrap.min.css">`引入）
*   Bootstrap 5 JS 文件（用于响应式交互，已在页脚引入）
*   自定义 CSS 样式（`index.css`中定义的主题变量和动画效果）

###### 核心布局结构

```html
<nav class="navbar navbar-expand-lg bg-body-tertiary fixed-top" data-bs-theme="dark">
  <div class="container">
    <!-- 品牌标识 -->
    <a class="navbar-brand" href="#">LayZ</a>
    
    <!-- 移动端折叠按钮 -->
    <button class="navbar-toggler" type="button" ...>
      <span class="navbar-toggler-icon"></span>
    </button>
    
    <!-- 导航菜单 -->
    <div class="collapse navbar-collapse" id="navbarSupportedContent">
      <ul class="navbar-nav me-auto mb-2 mb-lg-0">
        <!-- 导航项 -->
      </ul>
    </div>
  </div>
</nav>
```

###### 关键类与属性解析

*   `navbar`：基础导航栏类，定义核心样式
*   `navbar-expand-lg`：在大屏幕（lg 及以上）展开菜单，小屏幕自动折叠
*   `bg-body-tertiary`：基础背景色（配合`data-bs-theme="dark"`实现深色主题）
*   `fixed-top`：固定在页面顶部
*   `data-bs-theme="dark"`：启用深色主题模式
*   `container`：限制导航栏内容宽度，保持与页面其他内容对齐

###### 响应式设计实现

*   **移动端**：导航菜单自动折叠为汉堡按钮（`navbar-toggler`），点击后通过 JS 展开
*   **大屏幕**：菜单默认展开，使用水平布局
*   触发断点：通过`navbar-expand-lg`设定在`992px`宽度时切换布局

1\. HTML结构实现

折叠按钮组件：

```html
<button class="navbar-toggler" type="button" 
        data-bs-toggle="collapse" 
        data-bs-target="#navbarSupportedContent"
        aria-controls="navbarSupportedContent" 
        aria-expanded="false" 
        aria-label="Toggle navigation">
  <span class="navbar-toggler-icon"></span>
</button>
```

折叠内容区域：

```html
<div class="collapse navbar-collapse" id="navbarSupportedContent">
  <ul class="navbar-nav me-auto mb-2 mb-lg-0">
    <!-- 导航项列表 -->
  </ul>
</div>
```

2\. 关键属性解析

> **data-bs-toggle="collapse"**：
> 
> *   这是Bootstrap的JavaScript触发器
>     
> *   告诉Bootstrap这是一个折叠切换按钮
>     

> **data-bs-target="#navbarSupportedContent"**：
> 
> *   指定要折叠/展开的目标元素
>     
> *   使用CSS选择器指向id="navbarSupportedContent"的div
>     

> **aria属性（无障碍支持）**：
> 
> *   aria-controls="navbarSupportedContent"：关联控制的目标元素
>     
> *   aria-expanded="false"：初始状态为折叠（false）
>     
> *   aria-label="Toggle navigation"：为屏幕阅读器提供描述
>     

3\. Bootstrap响应式机制

> **断点控制**：
> 
> *   navbar-expand-lg：在≥992px（large）屏幕时展开导航栏
>     
> *   在<992px屏幕时自动折叠，显示汉堡菜单
>     
> 
> **CSS类作用**：
> 
> *   .navbar-toggler：汉堡按钮样式
>     
> *   .navbar-toggler-icon：三条横线图标
>     
> *   .collapse：初始隐藏状态
>     
> *   .navbar-collapse：导航栏折叠内容容器
>     

4\. JavaScript交互逻辑

> **Bootstrap自动处理**：
> 
> *   点击汉堡按钮时，Bootstrap自动切换aria-expanded属性
>     
> *   动态添加/移除.show类来控制显示/隐藏
>     
> *   平滑的过渡动画效果
>     
> 
> **状态管理**：
> 
> *   展开时：aria-expanded="true" + 添加.show类
>     
> *   折叠时：aria-expanded="false" + 移除.show类
>     

5\. 响应式行为

> **大屏幕（≥992px）**：
> 
> *   导航栏水平展开显示所有菜单项
>     
> *   汉堡按钮隐藏
>     
> 
> **小屏幕（<992px）**：
> 
> *   导航栏折叠，只显示品牌标识和汉堡按钮
>     
> *   点击汉堡按钮展开垂直菜单列表
>     
> *   菜单项垂直堆叠排列
>     

###### 自定义样式（来自 index.css）

导航栏背景与特效

```javascript
.navbar {
  background-color: rgba(18, 18, 18, 0.6) !important; /* 半透明深色背景 */
  backdrop-filter: blur(10px); /* 毛玻璃效果 */
  border-bottom: 1px solid rgba(255, 255, 255, 0.1); /* 底部边框 */
  padding: 15px 0;
}
```

导航链接样式

```javascript
.nav-link {
  position: relative;
  color: rgba(255, 255, 255, 0.9);
  margin: 0 12px;
}

/* 鼠标悬停效果 */
.nav-link:hover {
  text-shadow: var(--neon-glow); /* 霓虹灯文字阴影 */
}

/* 下划线动画 */
.nav-link::after {
  content: '';
  position: absolute;
  left: 0;
  bottom: -5px;
  width: 0;
  height: 2px;
  background: linear-gradient(90deg, var(--lay-cyan), var(--lay-blue));
  transition: all .3s; /* 平滑过渡 */
}

.nav-link:hover::after {
  width: 100%; /* 下划线展开效果 */
}
```

品牌标识样式

```javascript
.navbar-brand,
.navbar-brand:hover {
  font-size: 28px;
  font-weight: 700;
  background: linear-gradient(45deg, var(--lay-cyan), var(--lay-blue));
  -webkit-background-clip: text;
  background-clip: text;
  color: transparent; /* 渐变文字效果 */
}
```

###### 交互功能实现

*   **锚点导航**：通过`href="#banner"`等锚点链接实现页面内平滑跳转
*   **当前页高亮**：使用`active`类标记当前页面（首页默认高亮）
*   **移动端折叠**：通过`data-bs-toggle="collapse"`和`data-bs-target`属性配合 JS 实现折叠 / 展开

###### 响应式适配（媒体查询）

在小屏幕设备上的优化：

```javascript
@media (max-width: 768px) {
  .navbar {
    padding: 5px 0; /* 减少 padding 节省空间 */
  }
}
```
