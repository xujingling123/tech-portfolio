---### 一、父子组件对话的基本功：数据怎么传？

#### 1\. 爸爸给儿子送东西：父传子（props）

就像爸爸给儿子递玩具，父组件用`props`给子组件传数据，Vue2 和 Vue3 的区别主要在写法：

##### Vue2（传统写法）

**爸爸组件**（父组件）：

```html
<template>
  <!-- 把"parentMessage"这个数据用v-bind（冒号）传给儿子组件，这里的message是子组件声明接收的props名称 -->
  <ChildComponent :message="parentMessage" />
</template>

<script>
import ChildComponent from './ChildComponent.vue';
export default {
  components: { ChildComponent },
  // 定义响应式数据，组件实例创建时会自动将data中的数据进行响应式处理
  data() {
    return {
      parentMessage: 'Hello from parent!'
    };
  }
};
</script>
```

**儿子组件**（子组件）：

```html
<template>
  <!-- 直接显示从父组件接收的数据 -->
  <div>{{ message }}</div>
</template>

<script>
export default {
  // 声明接收的props，这里的message要和父组件传递的名称一致
  props: ['message'] 
};
</script>
```

##### Vue3（新写法更简洁）

**爸爸组件**：

```html
<template>
  <!-- 写法和Vue2差不多，但数据要用ref变成响应式，这样数据变化时视图会自动更新 -->
  <ChildComponent :message="parentMessage" />
</template>

<script setup>
import ChildComponent from './ChildComponent.vue';
import { ref } from 'vue';
// 使用ref创建响应式数据，在模板中可以直接使用
const parentMessage = ref('Hello from parent!'); 
</script>
```

**儿子组件**：

```html
<template>
  <!-- 还是显示message，但要用defineProps声明接收 -->
  <div>{{ message }}</div>
</template>

<script setup>
// 使用defineProps声明接收的props，同时可以进行类型推断
const props = defineProps({
  message: String
});
</script>
```

#### 2\. 儿子找爸爸帮忙：子传父（自定义事件）

儿子想告诉爸爸事情，就得喊爸爸注意 —— 子组件用`$emit`发信号，父组件用`v-on`（@）监听：

##### Vue2（传统写法）

**儿子组件**：

```html
<template>
  <!-- 点击按钮时，触发"sendToParent"方法，该方法会发出自定义事件 -->
  <button @click="sendToParent">点我告诉爸爸</button>
</template>

<script>
export default {
  methods: {
    sendToParent() {
      // 触发"child-event"自定义事件，并传递数据'Hello from child!'
      this.$emit('child-event', 'Hello from child!'); 
    }
  }
};
</script>
```

**爸爸组件**：

```html
<template>
  <!-- 监听儿子组件的"child-event"事件，收到后调用handleChildEvent方法 -->
  <ChildComponent @child-event="handleChildEvent" />
  <p>Received: {{ receivedMessage }}</p>
</template>

<script>
import ChildComponent from './ChildComponent.vue';
export default {
  components: { ChildComponent },
  data() {
    return {
      receivedMessage: ''
    };
  },
  methods: {
    handleChildEvent(message) {
      // 将子组件传递过来的数据赋值给组件的响应式数据
      this.receivedMessage = message; 
    }
  }
};
</script>
```

##### Vue3（新写法更清晰）

**儿子组件**：

```html
<template>
  <!-- 按钮点击逻辑一样，但用defineEmits声明能发什么信号 -->
  <button @click="sendToParent">点我告诉爸爸</button>
</template>

<script setup>
// 定义可触发的自定义事件，这里声明了'child-event'事件
const emit = defineEmits(['child-event']); 
const sendToParent = () => {
  // 触发'child-event'事件，并传递数据'Hello from child!'
  emit('child-event', 'Hello from child!'); 
}
</script>
```

**爸爸组件**：

```html
<template>
  <!-- 监听方式和Vue2一样，但数据用ref包裹使其成为响应式 -->
  <ChildComponent @child-event="handleChildEvent" />
  <p>Received: {{ receivedMessage }}</p>
</template>

<script setup>
import { ref } from 'vue';
import ChildComponent from './ChildComponent.vue';
// 创建响应式数据，用于存储子组件传递过来的数据
const receivedMessage = ref(''); 
const handleChildEvent = (message) => {
  // 将子组件传递过来的数据赋值给响应式数据
  receivedMessage.value = message; 
}
</script>
```

### 二、传函数就像爸爸给儿子工具：这些坑要避开！

有时候爸爸会给儿子一个工具（函数），让儿子在特定时候用，但这 3 个地方最容易出错：

#### 1\. 工具别拿错主人：函数上下文（this）问题

*   ❌ 错误示范（箭头函数让工具忘了主人）：
    
    ```html
    <!-- 箭头函数里的this不是指向父组件，而是外层作用域，导致函数执行时上下文错误 -->
    <ChildComponent :callback="() => this.doSomething()" />
    ```
    
*   ✅ 正确做法（直接传爸爸的方法名）：
    
    ```html
    <!-- 直接写方法名，函数会自动绑定到父组件实例，保证this指向正确 -->
    <ChildComponent :callback="doSomething" />
    ```
    

#### 2\. 别重复做一样的工具：性能优化

*   ❌ 不好的写法（每次渲染都做新工具，儿子频繁更新）：
    
    ```html
    <!-- 内联函数每次渲染都会生成新的函数实例，导致子组件不必要地重新渲染 -->
    <ChildComponent :callback="() => console.log('hello')" />
    ```
    
*   ✅ 推荐写法（提前做好工具，重复使用）：
    
    ```html
    <!-- 在父组件里先定义好方法，直接传名字，避免重复创建函数实例 -->
    <ChildComponent :callback="parentCallback" />
    
    <script setup>
    const parentCallback = () => { 
      console.log('hello');
    };
    </script>
    ```
    

#### 3\. 工具要贴使用说明：TypeScript 类型定义（Vue3 适用）

如果用 TypeScript，就像给工具贴使用说明，明确参数和返回值：

```javascript
<script setup lang="ts">
// 明确告诉Vue：这个callback函数需要接收一个字符串参数，并且没有返回值
const props = defineProps<{ 
  callback: (text: string) => void;
}>();
</script>
```

#### 4\. 什么时候用事件 vs 传函数？

*   **用事件（推荐）**：当子组件主动产生状态变化，需要通知父组件时使用，比如按钮点击、数据加载完成等场景，就像儿子主动喊爸爸。
*   **用传函数**：适用于父组件将特定逻辑注入子组件的场景，比如表单校验函数、网络请求函数等，儿子在特定时机调用，就像爸爸给儿子一把剪刀，让他需要时剪东西。

### 三、常见问题排雷指南

#### 问题 1：儿子调用爸爸的函数时没传参数

```javascript
// ❌ 错误：没带数据，爸爸的函数收不到信息，可能导致函数执行异常
this.callback() 

// ✅ 正确：把数据带上，确保函数能正常处理
this.callback(someData); 
```

#### 问题 2：爸爸的函数是异步的（比如需要等网络请求）

```javascript
// 爸爸的异步工具（需要等待结果）
const asyncFunction = async () => {
  const result = await fetch('https://api.com/data');
  return result.json();
}

// 儿子使用时要加async await
const sonUseFunction = async () => {
  const data = await props.callback(); // 加await等爸爸返回结果
  console.log(data);
}
```

#### 问题 3：函数调用太频繁，想做防抖（比如搜索框实时搜索）

可以用 Lodash 的 debounce 函数，让爸爸的函数等用户输入完再执行：

```javascript
// 引入debounce函数
import { debounce } from 'lodash';

// 爸爸先把工具防抖处理好，300毫秒内多次调用只会执行最后一次
const debouncedSearch = debounce((keyword) => {
  console.log('搜索:', keyword);
}, 300); 

// 传给儿子的是防抖后的工具
<ChildComponent :search="debouncedSearch" />
```

### 四、总结：一句话记住核心

*   **父传子**：爸爸用`props`给儿子送数据（Vue3 用`defineProps`声明，数据用`ref`变成响应式）。
*   **子传父**：儿子用`$emit`（Vue2）或`defineEmits`（Vue3）发信号，爸爸用**`@事件名`**监听。
*   **传函数注意**：别用箭头函数导致上下文错乱，提前定义函数避免性能问题，复杂场景加类型定义和防抖节流优化。
