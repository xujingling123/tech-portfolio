---### 1\. HTML布局结构

```html
<section class="picture py-5" id="section4">
  <div class="container py-5">
    <h2 class="text-center fw-bold display-4">照片墙</h2>
    <p class="text-center fs-6 mt-3 info">快门瞬间定格你我，提起你的成长，还是会泪流</p>
  </div>
  <div class="row mt-5">
    <div class="box">
      <div class="item"><img src="img/zyx-img1.jpg" alt="1"></div>
      <div class="item"><img src="img/zyx-img2.jpg" alt="2"></div>
      <div class="item"><img src="img/zyx-img3.jpg" alt="3"></div>
      <div class="item"><img src="img/zyx-img4.jpg" alt="4"></div>
      <div class="item"><img src="img/zyx-img5.jpg" alt="5"></div>
    </div>
  </div>
</section>
```

> 结构特点：
> 
> \- 使用Bootstrap的容器系统（ .container ）确保内容居中  
> \- 标题区域采用响应式排版（ .display-4 、 .fs-6 ）  
> \- 图片容器使用Flexbox布局（ .box ）  
> \- 每个图片项使用相同的 .item 类，便于统一样式控制

### 2.3D悬停相册实现

```javascript
.picture .box {
  display: flex;
  justify-content: center;
  align-items: center;
}

.picture .box .item {
  position: relative;
  width: 220px;
  height: 250px;
  margin: 0 2px;
  cursor: pointer;
  /* 添加倒影 */
  -webkit-box-reflect: below 1px linear-gradient(transparent, #0002);
  transition: all .6s;
}
```

> \- Flexbox居中布局 ： .box 使用 display: flex 配合 justify-content: center 和 align-items: center 实现完美居中  
> \- 固定尺寸 ：每个 .item 设置固定宽高（220px × 250px），确保布局一致性  
> \- 镜像效果 ：使用 -webkit-box-reflect 属性创建底部镜像，增强视觉层次感

3D变换与交互效果：

```javascript
/* 鼠标经过某个盒子，当前盒子变大 */
.picture .box .item:hover {
  transform: scale(1.4);
  z-index: 1;
}

/* 鼠标经过某个盒子，其余的子盒子都变形，当前盒子保持不变 */
.picture .box:hover .item:not(:hover) {
  transform: perspective(500px) scale(0.9) rotateY(45deg);
  margin: 0 -20px;
}

/* 鼠标经过的盒子，后面的兄弟（姐妹）修改下变形 */
.picture .box .item:hover~.item {
  transform: perspective(500px) scale(0.9) rotateY(-45deg);
}
```

> 技术实现原理：
> 
> *      悬停放大效果 ：
> 
>    - 鼠标悬停时，当前图片放大1.4倍（ scale(1.4) ）  
>    - 设置 z-index: 1 确保放大图片位于其他图片之上
> 
> *      3D透视变换 ：
> 
>    - 使用 perspective(500px) 创建3D透视空间  
>    - 非悬停图片缩小到0.9倍并沿Y轴旋转45度  
>    - 通过负边距（ margin: 0 -20px ）实现紧凑布局
> 
> *      兄弟选择器应用 ：
> 
>    - 使用 ~ 选择器选中悬停图片之后的所有兄弟元素  
>    - 这些元素沿Y轴反向旋转-45度，形成对称的3D效果

镜像反射效果：

```javascript
-webkit-box-reflect: below 1px linear-gradient(transparent, #0002);
```

> \- 在图片下方创建1px高度的镜像  
> \- 使用渐变遮罩实现从透明到半透明的平滑过渡  
> \- 增强图片的立体感和视觉深度
