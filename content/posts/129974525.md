---该题最小的三位数是：123，最大的三位数是：432

所以就可以在这个区间里面找，用for循环生成数字，然后再根据个位，十位，百位的数字用if语句判断。

代码：

```cpp
int main() {
    int i,a,b,c, sum = 0;
    for (i = 123; i <= 432; i++) {
        a = i % 10;//个位数
        b = i / 10 % 10;//十位数
        c = i / 100;//百位数
        if (a != b && a != c && b != c && (a > 0) && (a < 5) && (b > 0) && (b < 5) && (c > 0) && (c < 5)) {
            sum++;
            printf("%d\n", i);
        }
        
    }
    printf("个数：%d\n", sum);

    return 0;
}
```
