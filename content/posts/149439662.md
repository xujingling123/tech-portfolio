---### 一、NVM 是什么？

NVM（Node Version Manager）是一个开源的 Shell 脚本，用于管理多个 Node.js 版本。它支持 macOS、Linux 以及 Windows（通过 `nvm-windows`）。使用 NVM，你可以：

*   安装任意版本的 Node.js
*   在不同版本之间快速切换
*   设置默认 Node.js 版本
*   查看已安装和可用的 Node.js 版本

### 二、NVM 常用命令

以下命令适用于 macOS/Linux 和 Windows（命令基本一致）。

#### 1\. 查看 NVM 版本

```
nvm --version
```

#### ![](https://i-blog.csdnimg.cn/direct/871e49fe7a2e41d59acd5e156994baa6.png)

#### 2\. 安装指定版本的 Node.js

```
nvm install 18.17.0
```

安装最新 LTS 版本：

```
nvm install --lts
```

安装最新版本：

```
nvm install node
```

#### 3\. 查看已安装的 Node.js 版本

```
nvm list
```

或：

```
nvm ls
```

#### ![](https://i-blog.csdnimg.cn/direct/9f15fb23a8f1494aaf5a9a1897bc47cc.png)

#### 4\. 切换 Node.js 版本

```
nvm use 版本号
```

#### ![](https://i-blog.csdnimg.cn/direct/80a2d97372964d2bb8f6191636932147.png)

#### 5\. 设置默认 Node.js 版本

```
nvm alias default 18.17.0
```

设置后，每次打开新终端时将自动使用该版本。

#### 6\. 查看当前使用的 Node.js 版本

```
nvm current
```

#### ![](https://i-blog.csdnimg.cn/direct/9637413ac24045af8bb095b00a26e674.png)

#### 7\. 卸载某个 Node.js 版本

```
nvm uninstall 版本号
```

#### 8\. 获取 Node.js 或 npm 的安装路径

```
nvm which 18.17.0
```

安装对应版本node

```bash
nvm install 20.17.0
```

进入或切换版本

```bash
nvm use 20.17.0
```
