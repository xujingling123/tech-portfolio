---## 一、CSS选择器优先级：从高到低的完整规则

CSS选择器的优先级决定了当多个样式规则作用于同一元素时，哪条规则会被优先应用。其核心规则基于​**​选择器的类型权重​**​，可通过“权重值”量化比较。

#### 1.1 优先级从高到低排序

选择器类型

权重值（近似值）

说明

内联样式（`style`属性）

1000

直接写在HTML元素`style`属性中的样式（如`<div style="color:red">`）

ID选择器（`#id`）

100

根据元素的`id`属性匹配（如`#header`）

类选择器（`.class`）、伪类（`:hover`）、属性选择器（`[type="text"]`）

10

匹配类名、伪类状态或元素属性（如`.btn:hover`、`input[type="text"]`）

元素选择器（`div`）、伪元素（`::before`）

1

匹配标签名或伪元素（如`div`、`::first-line`）

通配符选择器（`*`）

0

匹配所有元素（如`* { margin:0 }`）

#### 1.2 关键规则补充

*   ​**​权重值累加​**​：复杂选择器的权重是各部分权重之和。例如：  
    `#header .nav-item:hover` 的权重 = ID（100） + 类（10） + 伪类（10） = 120。
*   ​**​`!important`的特殊性​**​：`!important`标记的样式优先级最高（高于内联样式），但属于“强制覆盖”，不参与正常权重计算。例如：
    
    ```javascript
    .btn { color: red !important; } /* 会覆盖ID选择器的color样式 */
    ```
    
*   ​**​就近原则​**​：当权重值相同时，后定义的样式会覆盖先定义的样式（CSS层叠性）。

#### 1.3 类选择器 vs ID选择器

​**​ID选择器的优先级远高于类选择器​**​（权重100 vs 10）。例如：

```javascript
#header { color: blue; }    /* 权重100 */
.header { color: red; }     /* 权重10 */
```

即使`.header`选择器在CSS中后定义，`#header`的样式仍会生效（除非`.header`使用`!important`）。

### 二、兄弟节点选择：相邻与通用的区别

兄弟节点指同一父元素下的同级元素（如`<div>`和`<p>`同为`<body>`的子元素）。CSS提供了两种选择器来定位兄弟节点：

#### 2.1 相邻兄弟选择器（`+`）

选择​**​紧接在目标元素之后​**​的第一个同层级兄弟元素（仅匹配一个）。  
​**​语法​**​：`前驱元素 + 目标元素`

​**​示例​**​：

```html
<div class="box"></div>
<p>我是紧接在div后的段落</p>  <!-- 会被选中 -->
<p>我是div后的第二个段落</p>  <!-- 不会被选中 -->
```

```javascript
.box + p { 
  color: red; /* 仅第一个p元素变红 */
}
```

#### 2.2 通用兄弟选择器（`~`）

选择​**​目标元素之后所有同层级兄弟元素​**​（匹配多个）。  
​**​语法​**​：`前驱元素 ~ 目标元素`

​**​示例​**​：

```html
<div class="box"></div>
<p>我是div后的第一个段落</p>  <!-- 会被选中 -->
<p>我是div后的第二个段落</p>  <!-- 会被选中 -->
<span>我是div后的span</span>  <!-- 不会被选中（非p元素） -->
```

```javascript
.box ~ p { 
  color: blue; /* 两个p元素都变蓝 */
}
```

#### 2.3 注意事项

*   前驱元素必须​**​在目标元素之前​**​（即“前驱”是相对顺序）；
*   兄弟节点必须是​**​同一父元素下的直接子元素​**​（孙元素或更深层级不匹配）；
*   伪类（如`:nth-child`）可与兄弟选择器结合使用（如`div + p:first-child`）。

### 三、查询网页所有图片：方法与选择器

#### 3.1 常用查询方法

要获取页面中所有`<img>`元素，可通过以下两种方式：

##### （1）`document.getElementsByTagName('img')`

返回一个​**​动态的HTMLCollection​**​（实时反映DOM变化）。  
​**​特点​**​：

*   实时更新：若后续新增或删除`<img>`元素，集合会自动变化；
*   只能通过索引访问（如`images[0]`），不支持CSS选择器过滤。

​**​示例​**​：

```javascript
const images = document.getElementsByTagName('img');
console.log(images.length); // 输出当前页面图片数量
// 遍历所有图片
for (let i = 0; i < images.length; i++) {
  console.log(images[i].src); // 输出每张图片的src
}
```

##### （2）`document.querySelectorAll('img')`

返回一个​**​静态的NodeList​**​（不随DOM变化自动更新）。  
​**​特点​**​：

*   静态快照：仅包含查询时的图片元素；
*   支持CSS选择器扩展（如`img[src*="logo"]`筛选含“logo”的图片）。

​**​示例​**​：

```javascript
const images = document.querySelectorAll('img');
console.log(images.length); // 输出当前页面图片数量
// 遍历所有图片（NodeList可直接用forEach）
images.forEach(img => {
  console.log(img.alt); // 输出每张图片的alt属性
});
// 筛选特定图片（如宽度大于500px的图片）
const largeImages = document.querySelectorAll('img[width]>500');
```

#### 3.2 选择器写法

*   基础选择器：`img`（匹配所有`<img>`标签）；
*   属性选择器：`img[src]`（匹配有`src`属性的图片）、`img[src="logo.png"]`（匹配指定`src`的图片）；
*   伪类选择器：`img:hover`（鼠标悬停时的图片）、`img:first-of-type`（父元素中第一个`<img>`）；
*   组合选择器：`div.container > img`（匹配`class="container"`的`<div>`下的直接子`<img>`）。

### 四、Window变量与Document方法详解

#### 4.1 Window对象：浏览器的全局容器

`window`是浏览器的顶级对象，代表一个浏览器窗口或标签页，包含与窗口相关的属性和方法。常见用途包括：

属性/方法

说明

`window.location`

操作当前页面的URL（如`location.href`获取完整URL，`location.reload()`刷新页面）

`window.navigator`

获取浏览器/设备信息（如`navigator.userAgent`获取用户代理字符串）

`window.screen`

获取屏幕信息（如`screen.width`屏幕宽度，`screen.colorDepth`色彩深度）

`window.alert()`

弹出警告框

`window.confirm()`

弹出确认框（返回`true`/`false`）

`window.prompt()`

弹出输入框（返回用户输入的字符串）

`window.setTimeout()`

延迟执行代码（返回定时器ID，可用`clearTimeout`取消）

`window.setInterval()`

周期性执行代码（返回定时器ID，可用`clearInterval`取消）

`window.document`

获取当前页面的`Document`对象（操作DOM的入口）

#### 4.2 Document对象：DOM操作的入口

`Document`对象代表整个HTML文档，提供了一系列方法用于操作DOM元素。常见方法包括：

方法

说明

`getElementById(id)`

根据ID获取单个元素（返回`Element`对象，不存在返回`null`）

`querySelector(selector)`

根据CSS选择器获取​**​首个匹配​**​元素（返回`Element`对象）

`querySelectorAll(selector)`

根据CSS选择器获取​**​所有匹配​**​元素（返回`NodeList`）

`createElement(tagName)`

创建新元素（如`document.createElement('div')`）

`createTextNode(text)`

创建文本节点（如`document.createTextNode('Hello')`）

`appendChild(node)`

将节点添加为父元素的最后一个子节点

`removeChild(node)`

从父元素中移除指定子节点

`getElementByTagName(tag)`

根据标签名获取元素集合（返回`HTMLCollection`，动态更新）

`getElementByClassName(class)`

根据类名获取元素集合（返回`HTMLCollection`，动态更新）

​**​示例：动态添加图片​**​

```javascript
// 创建img元素
const newImg = document.createElement('img');
newImg.src = 'https://example.com/new-image.jpg';
newImg.alt = '新图片';

// 添加到body的末尾
document.body.appendChild(newImg);

// 或添加到某个div中
const container = document.getElementById('container');
container.appendChild(newImg);
```

### 总结

*   ​**​CSS选择器优先级​**​：内联样式 > ID > 类/伪类/属性 > 元素/伪元素 > 通配符；
*   ​**​兄弟节点选择​**​：`+`选相邻第一个，`~`选后续所有；
*   ​**​图片查询​**​：`getElementsByTagName`（动态）或`querySelectorAll`（静态）；
*   ​**​Window与Document​**​：`window`是全局容器，`Document`是DOM操作入口，掌握常用方法可高效完成页面交互与数据操作。
