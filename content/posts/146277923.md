安装之前的tips:

#### 版本选择建议

为了避免潜在的版本冲突，建议选择合适的 MySQL Workbench 版本：

*   如果使用 MySQL 5.7，可以选择 MySQL Workbench 6.3 或 8.0 版本。其中 MySQL Workbench 6.3 是专门为 MySQL 5.x 设计的版本，兼容性较好；而 MySQL Workbench 8.0 虽然是较新的版本，但也能很好地支持 MySQL 5.7。
*   如果使用 MySQL 5.6，建议选择 MySQL Workbench 6.x 系列版本，该系列版本对 MySQL 5.6 的支持更加稳定。

检查自己数据库的版本：

##### 方法：通过 MySQL 命令行客户端

1.  **打开命令提示符**：按下 `Win + R` 组合键，输入 `cmd` 并回车，打开命令提示符窗口。
2.  **登录 MySQL**：在命令提示符中输入以下命令登录到 MySQL，其中 `your_username` 是你的 MySQL 用户名，按提示输入密码。

```
mysql -u your_username -p
```

1.  **查看版本**：登录成功后，输入以下 SQL 语句查看 MySQL 版本。

```
SELECT VERSION();
```

执行该语句后，会返回当前 MySQL 的版本信息。
