---### 1.HTML布局结构

```html
<section class="shell py-5" id="section5">
  <div class="container py-5">
    <h2 class="text-center fw-bold display-4">珍珠会藏于贝类</h2>
    <p class="text-center fs-6 mt-3 info">未来无限大，我们一起走，然后各自幸福</p>
  </div>
  <div class="row mt-5">
    <div class="box">
      <!-- 滚动盒子 -->
      <div class="scroll">
        <!-- 第一组 -->
        <div class="ad1">
          <div class="ad1-item"><img src="img/zyx-xback1.jpg" alt=""></div>
          <div class="ad1-item"><img src="img/zyx-xback2.jpg" alt=""></div>
          <!-- ... 共24个ad1-item -->
        </div>
        <!-- 第二组 -->
        <div class="ad1">
          <div class="ad1-item"><img src="img/zyx-xback23.jpg" alt=""></div>
          <div class="ad1-item"><img src="img/zyx-xback24.jpg" alt=""></div>
          <!-- ... 共15个ad1-item -->
        </div>
      </div>
    </div>
  </div>
</section>
```

> 结构特点：
> 
> \- 使用Bootstrap的容器系统（ .container ）确保内容居中  
> \- 标题区域采用响应式排版（ .display-4 、 .fs-6 ）  
> \- 核心滚动容器采用三层嵌套结构： .box → .scroll → .ad1  
> \- 每组 .ad1 包含多个 .ad1-item 图片项，实现无缝循环滚动

### 2.无缝滚动效果实现

```javascript
.shell .box {
  overflow: hidden;
  width: 1180px;
  margin: 0 auto;
}
```

> \- 隐藏溢出 ： overflow: hidden 确保滚动内容在容器内显示  
> \- 固定宽度 ：设置1180px固定宽度，控制滚动区域范围  
> \- 居中显示 ： margin: 0 auto 实现水平居中

滚动动画实现：

```javascript
.shell .scroll {
  display: flex;
  animation: move3 20s linear infinite;
}

@keyframes move3 {
  0% {
    transform: translateX(0);
  }
  100% {
    transform: translateX(-1200px);
  }
}
```

> 技术实现原理：  
>    Flex布局 ： .scroll 使用 display: flex 实现水平排列  
>    CSS动画 ：应用 move3 关键帧动画，持续20秒，线性运动，无限循环  
>    平移变换 ：从0px平移到-1200px，实现向左滚动效果

```javascript
.shell .scroll .ad1 {
  display: grid;
  grid-template-columns: repeat(8, 220px);
  grid-template-rows: repeat(3, 180px);
  gap: 16px 20px;
  margin-right: 20px;
}
```

> 网格布局特点：
> 
> \- 8列3行 ：每个 .ad1 组创建8列×3行的网格布局  
> \- 固定尺寸 ：每列220px宽，每行180px高  
> \- 间距控制 ：行间距16px，列间距20px  
> \- 组间间距 ： margin-right: 20px 设置组间距离

```javascript
.shell .scroll .ad1 .ad1-item {
  width: 220px;
  height: 180px;
  border-radius: 6px;
  /* 图片溢出隐藏 */
  overflow: hidden;
}
```

> 图片处理：
> 
> \- 尺寸匹配 ：与网格单元格尺寸完全匹配  
> \- 圆角设计 ：6px圆角增强视觉美感  
> \- 溢出隐藏 ：确保图片在容器内正常显示

悬停暂停效果：

```javascript
.shell .box:hover .scroll {
  animation-play-state: paused;
}
```

图片放大效果：

```javascript
.shell .scroll .ad1 img:hover {
  transform: scale(1.2);
  transition: all .5s;
}
```
