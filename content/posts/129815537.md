---首先要了解什么是水仙花数？

水仙花数：是指一个 3 位数，它的每个位上的数字的 3次幂之和等于它本身。例如：1^3 + 5^3+ 3^3 = 153。

代码：

```cpp
//求水仙花数

#include <stdio.h>
#include <stdlib.h>
int fun(int n)
{
	int a, b, c;
	a = n / 100;
	b = n/10%10;
	c = n % 10;
	return a * a * a + b * b * b + c * c * c;

}
int main()
{
	int i;
	for (i = 100; i < 1000; i++)
	{
		if (i == fun(i))
			printf("%d是水仙花数\n", i);

	}
	return 0;
}
```
