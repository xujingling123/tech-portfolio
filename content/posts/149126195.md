---### 一、核心存储方案选择：`localStorage`

要实现跨页面关闭的数据持久化，需选择​**​持久化存储介质​**​。前端常用存储方案对比如下：

​**​结论​**​：`localStorage` 是最适合本场景的选择——容量足够（支持万字文本）、使用简单（同步API）、生命周期符合“长期保存”需求。

### 二、基础实现：实时保存与恢复

#### 2.1 页面加载时恢复内容

在页面初始化阶段（如`DOMContentLoaded`或`load`事件），从`localStorage`读取保存的内容，并填充到文本框中。

```html
<!-- HTML -->
<textarea id="myTextarea" placeholder="输入内容..."></textarea>
```

```javascript
// JavaScript
window.addEventListener('DOMContentLoaded', () => {
  const textarea = document.getElementById('myTextarea');
  // 从localStorage读取保存的内容（键名自定义，如'textareaContent'）
  const savedContent = localStorage.getItem('textareaContent');
  if (savedContent) {
    textarea.value = savedContent; // 恢复内容
  }
});
```

#### 2.2 输入时实时保存内容

监听文本框的`input`事件（用户输入、删除、粘贴等操作均会触发），将最新内容保存到`localStorage`。

```javascript
const textarea = document.getElementById('myTextarea');
textarea.addEventListener('input', (e) => {
  // 将当前输入内容保存到localStorage
  localStorage.setItem('textareaContent', e.target.value);
});
```

​**​效果验证​**​：  
输入文字→关闭页面→重新打开，文本框会显示最后一次输入的内容。

### 三、进阶优化：应对复杂场景

#### 3.1 防抖（Debounce）：减少频繁写入

用户输入时，`input`事件会高频触发（如每输入一个字符触发一次）。若文本框内容较长，频繁写入`localStorage`可能影响性能。可通过​**​防抖函数​**​优化，确保用户停止输入一段时间后再保存。

```javascript
// 防抖函数（延迟500ms执行）
function debounce(func, delay = 500) {
  let timer;
  return (...args) => {
    clearTimeout(timer);
    timer = setTimeout(() => func.apply(this, args), delay);
  };
}

// 使用防抖包装保存逻辑
const saveContent = debounce((value) => {
  localStorage.setItem('textareaContent', value);
});

textarea.addEventListener('input', (e) => {
  saveContent(e.target.value); // 输入停止500ms后保存
});
```

#### 3.2 过期时间：避免无效数据长期占用

若希望内容仅在一定时间内有效（如24小时），可保存时记录时间戳，读取时检查是否过期。

```javascript
// 保存时添加时间戳
const saveWithExpire = (value, expireSeconds = 24 * 3600) => {
  const data = {
    value,
    expireAt: Date.now() + expireSeconds * 1000 // 过期时间戳（毫秒）
  };
  localStorage.setItem('textareaContent', JSON.stringify(data));
};

// 读取时检查是否过期
const getWithExpire = () => {
  const dataStr = localStorage.getItem('textareaContent');
  if (!dataStr) return null;
  const data = JSON.parse(dataStr);
  if (Date.now() > data.expireAt) {
    localStorage.removeItem('textareaContent'); // 过期则删除
    return null;
  }
  return data.value;
};

// 使用示例
textarea.addEventListener('input', (e) => {
  saveWithExpire(e.target.value); // 保存带过期时间的内容
});

// 页面加载时
const savedContent = getWithExpire();
if (savedContent) {
  textarea.value = savedContent;
}
```

#### 3.3 容错处理：避免存储异常

`localStorage` 可能因用户禁用、存储空间不足等原因写入失败，需添加异常捕获。

```javascript
textarea.addEventListener('input', (e) => {
  try {
    localStorage.setItem('textareaContent', e.target.value);
  } catch (err) {
    console.error('保存失败:', err);
    // 可选：提示用户“自动保存失败，请手动保存”
  }
});
```

### 四、扩展方案：使用`IndexedDB`存储大文本

若用户需要输入极长文本（如小说、长笔记），`localStorage`的5-10MB容量可能不足。此时可使用`IndexedDB`（支持250MB+存储），其异步API和事务机制更适合大文件操作。

#### 4.1 IndexedDB基础使用

```javascript
// 打开/创建数据库（名称'myDB'，版本1）
const request = indexedDB.open('myDB', 1);

// 首次创建或版本升级时初始化存储对象
request.onupgradeneeded = (event) => {
  const db = event.target.result;
  // 创建对象仓库（类似表），主键为自增id
  if (!db.objectStoreNames.contains('textStorage')) {
    db.createObjectStore('textStorage', { keyPath: 'id', autoIncrement: true });
  }
};

// 保存内容
function saveToIndexedDB(value) {
  const dbRequest = indexedDB.open('myDB', 1);
  dbRequest.onsuccess = (event) => {
    const db = event.target.result;
    const transaction = db.transaction(['textStorage'], 'readwrite');
    const store = transaction.objectStore('textStorage');
    // 插入数据（可自定义存储结构，如添加时间戳）
    store.add({ value, timestamp: Date.now() });
  };
}

// 读取内容（获取最新的一条）
function getFromIndexedDB(callback) {
  const dbRequest = indexedDB.open('myDB', 1);
  dbRequest.onsuccess = (event) => {
    const db = event.target.result;
    const transaction = db.transaction(['textStorage'], 'readonly');
    const store = transaction.objectStore('textStorage');
    const getRequest = store.getAll(); // 获取所有记录
    getRequest.onsuccess = () => {
      // 按时间戳倒序，取第一条（最新）
      const latest = getRequest.result.sort((a, b) => b.timestamp - a.timestamp)[0];
      callback(latest?.value);
    };
  };
}

// 使用示例
textarea.addEventListener('input', debounce((e) => {
  saveToIndexedDB(e.target.value); // 保存到大文本存储
}));

// 页面加载时
getFromIndexedDB((content) => {
  if (content) textarea.value = content;
});
```

### 五、总结与最佳实践

#### 5.1 方案选择建议

*   ​**​小量文本（<5MB）​**​：优先使用`localStorage`，简单高效；
*   ​**​大量文本（>5MB）​**​：使用`IndexedDB`，支持大容量和异步操作；
*   ​**​需要服务端同步​**​：结合`localStorage`+后端API（如用户登录后将内容保存到数据库）。

#### 5.2 最佳实践

*   ​**​键名规范​**​：使用唯一标识（如`user_${userId}_textarea`），避免不同用户/页面冲突；
*   ​**​隐私保护​**​：敏感内容（如密码）禁止明文存储，需加密（如使用`AES`）；
*   ​**​用户提示​**​：可添加“自动保存”提示（如输入时显示“已自动保存到本地”）；
*   ​**​兼容性​**​：`localStorage`和`IndexedDB`均支持现代浏览器（IE10+），旧浏览器需做降级处理。
