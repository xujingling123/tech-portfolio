---题目1：

设计一个算法计算一颗给定二叉树b中的所有双分支结点个数

代码：

```cpp
//求二叉树的双分支结点个数
int DSonNodes(BTNode* b) {
    if (b == NULL) return 0;
    if (b->lchild != NULL && b->rchild != NULL) {
        return 1 + DSonNodes(b->lchild) + DSonNodes(b->rchild);
    }
    else {
        return DSonNodes(b->lchild) + DSonNodes(b->rchild);
    }
}
```

题目2：

设计一个算法，求该二叉树中距离根结点最近的叶子结点

> 分析：该题可以使用先序遍历，从根结点开始找，然后min可以设置为结点个数n,p设置为当前的层次，然后在每次递归时，如果找到没有左子树和右子树的叶子结点x,则将该层次p赋给min，直到找到编号最小的叶子结点（也就是离根节点最近的叶子结点）

```cpp
void MinlenLeaf(BTNode* b, int p, int& min, char& x) {
    //p的初始值为1，min取总结点个数，x为所求的叶子结点
    if (b != NULL) {
        if (b->lchild == NULL && b->rchild == NULL) {
            if (p < min) {
                min = p;
            }
        }
        MinlenLeaf(b->lchild, p + 1; min, x);
        MinlenLeaf(b->rchild, p + 1; min, x);
    }
}
```

题目3：

假设二叉树采用二叉链存储结构进行存储，设计一个算法，采用先序遍历方法求二叉树b的宽度（即具有结点数最多的那一层上的结点总数）

代码：

```cpp
//求二叉树的宽度
void width1(BTNode* b, int h, int width[]) {
    //h的初始值为1
    if (b != NULL) {
        width[h]++;
        width1(b->lchild, h + 1, width);
        width1(b->rchild, h + 1, width);
    }
}
//假设有99个结点的二叉树，求其宽度
int Width(BTNode* b) {
    int i, max = 0;
    int width[100];
    for (i = 1; i < 100; i++) {
        width[i] = 0;
    }
    width1(b, 1, width);
    for (i = 1; i < 100; i++) {
        if (width[i] > max) max = width[i];
    }
    return max;
}
```

题目4：

假设二叉树采用二叉链存储结构存储。设计一个算法，利用结点的右孩子指针rchild将一颗二叉树的叶子结点按从左往右的顺序串成一个单链表。

代码：

```cpp
//将二叉树的叶子结点按从左往右的顺序串成一个单链表
void Link(BTNode* b, BTNode*& head, BTNode*& tail) {
    if (b != NULL) {
        if (b->lchild == NULL && b->rchild == NULL) {
            if (head == NULL) {
                head = b;
                tail = b;
            }//第一个叶子结点
            else {
                tail->rchild = b;
                tail = b;
            }
        }
        Link(b->lchild, head, tail);
        Link(b->rchild, head, tail);
    }
}
```

题目5：

假设二叉树中每个结点值为单个字符，采用二叉链存储结构存储。设计一个算法求二叉树b的最小枝长（根节点到最近叶子结点的路径长度）

代码:

```cpp
//求最小枝长
int MinBranch(BTNode* b) {
    int min1, min2, min;
    if (b == NULL) return 0;
    else {
        min1 = MinBranch(b->lchild);
        min2 = MinBranch(b->rchild);
        if (min1 < min2) min = min1 + 1;
        else min = min2 + 1;
        return min;
    }
}
```

题目：

假设二叉树中每个结点值为单个字符，采用二叉链存储结构存储。设计一个算法，求二叉树b中第k层上的叶子结点个数。

代码：

```cpp
//求第k层上的叶子结点个数
int LevelLeafkCount(BTNode* b, int h, int k) {
    //h的初始值是1
    int num1, num2, num = 0;
    if (b != NULL) {
        if (h == k && b->lchild == NULL && b->rchild == NULL) {
            num++;
        }
        num1 = LevelLeafkCount(b->lchild, h + 1, k);
        num2 = LevelLeafkCount(b->rchild, h + 1, k);
        num += num1 + num2;
        return num;
    }
    else {
        return 0;
    }
}
int LevelLeafk(BTNode* b, int k) {
    //求第k层上的叶子结点个数
    return LevelLeafkCount(b, 1, k);
}
```
