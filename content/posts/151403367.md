---### 问题：

当微信开发者工具上传代码时，出现Error: 代码包大小超过限制,main package source size 2113KB exceed max limit 2048KB \[20250910 09:15:31\]\[wx822e805b1c2c4ac2\] \[1.06.2504010\]\[win32-x64\]

### 一、创建新分支

在进行分包重构这类重大结构调整前，创建新分支是最好的方法

好处

说明

🔒 安全性

主分支不受影响，出错可回退

🧪 可实验

可尝试多种分包方案

🤝 协作

多人评审后再合并

🚫 防误提交

避免未完成代码上线

操作步骤：

1.查看当前分支

> git branch

![](https://i-blog.csdnimg.cn/direct/0e928617153c4df3bc3ca6cff4b91d08.png)

2.查看是否有未提交的更改

> git status

![](https://i-blog.csdnimg.cn/direct/55a41301e65f4411be7ae2e8aa46e425.png)

3.先提交或暂存当前修改

> git add .
> 
> git commit -m"保存当前工作进度'

4.创建并切换到分包专用分支

> git checkout -b feature-subpackage-weixin

![](https://i-blog.csdnimg.cn/direct/bdd485e26fb04a379747c0d9f3952633.png)

### 二、项目拆分

1.根据上传时给的依赖提示，来进行拆分，将主包里面耦合度低的部分先拆分出去

![](https://i-blog.csdnimg.cn/direct/3c8d2dff4d54436099a267288c793fd8.png)

2.保留主页和用户页面内容在主包，其他的尽量分给分包

![](https://i-blog.csdnimg.cn/direct/3899b2da7bd045ce9e13c90b3b9d2a27.png)

对应的pages.json文件也要修改：

![](https://i-blog.csdnimg.cn/direct/c6f99c10370d4aaaa3d37cc27fed6197.png)

3.拆分完成后，要运行看一下有没有报错之类的，一般报错都是路径问题，可以找到对应页面查看

![](https://i-blog.csdnimg.cn/direct/1a77eb19cec744068dd37b0e73dabaaa.png)

![](https://i-blog.csdnimg.cn/direct/a37e184d580d492d93d0d9ce297a215a.png)

成功运行，在微信开发者工具里面预览页面也是没有问题，就说明拆包成功了。

### 三、合并分支

1.切换到主分支

> git checkout feature-initial

![](https://i-blog.csdnimg.cn/direct/e0fa6b86c63642d88ba070159af91c8d.png)

2.合并之前创建的新分支

> git merge feature-sub-weixi

![](https://i-blog.csdnimg.cn/direct/0e76d49b63a441b1b1468d7addabfcd7.png)

这样就完美完成了分包处理！！！
