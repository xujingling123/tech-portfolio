---### 1\. HTML布局结构

```html
<section class="about py-5" id="section1">
  <div class="container py-5">
    <!-- 标题区域 -->
    <h2 class="text-center fw-bold display-4 zyx-title"></h2>
    <p class="text-center fs-6 mt-3 info">张艺兴简介...</p>
    
    <!-- 内容区域：图片墙 + 文字介绍 -->
    <div class="row mt-5">
      <div class="col-md-8">图片墙</div>
      <div class="col-md-4">文字介绍</div>
    </div>
  </div>
</section>
```

使用Bootstrap栅格系统，左侧8列展示图片墙，右侧4列展示文字介绍。

### 2.图片墙技术实现

图片墙容器设置

```javascript
.about .box {
  position: relative;
  height: 650px;
  overflow: hidden;
}
```

> 技术要点 ：
> 
> \- position: relative 为绝对定位的子元素提供参照  
> \- 固定高度确保布局稳定性  
> \- overflow: hidden 隐藏超出部分

每个卡片使用精确的绝对定位：

```javascript
.about .box .card1 {
  width: 215px; height: 164px;
  position: absolute;
  top: 31px; left: -1px;
}

.about .box .card2 {
  width: 242px; height: 135px;
  position: absolute;
  top: 40px; left: 225px;
}

.about .box .card3 {
  width: 701px; height: 428px;
  position: absolute;
  top: 160px; left: 0px;
}
```

通过精确的坐标定位，创建错落有致的图片排列，形成视觉层次感。

3D变换效果：

```javascript
.about .box > * {
  transform: rotateY(-20deg) rotateX(20deg);
  backdrop-filter: blur(10px);
  transition: all 2s cubic-bezier(0.075, 0.82, 0.165, 1);
}
```

> \- rotateY(-20deg) ：Y轴旋转-20度，创建立体感  
> \- rotateX(20deg) ：X轴旋转20度，增强透视效果  
> \- backdrop-filter: blur(10px) ：毛玻璃模糊效果  
> \- cubic-bezier ：自定义缓动函数，实现流畅动画

悬停动画效果：

```javascript
.about .box:hover .card1 {
  transform: translate3d(-30px, -30px, 0);
}

.about .box:hover .card2 {
  transform: translate3d(0, -30px, 0);
}

.about .box:hover .card3 {
  transform: translate3d(0, 0, 0);
}
```

> 交互逻辑 ：
> 
> \- 鼠标悬停时，每个卡片向不同方向移动  
> \- 使用 translate3d 实现3D平移，启用GPU加速  
> \- 移除初始的旋转角度，恢复平面状态

### 3.文字区域实现

图标和文字样式：

```javascript
.about .iconfont {
  font-size: 50px;
}

.about .text {
  font-size: 1.2rem;
  display: flex;
  align-items: center;
  justify-content: center;
}

.about .fw-light {
  text-indent: 2em;  /* 首行缩进2字符 */
}
```

> 排版细节 ：
> 
> \- 大号图标增强视觉冲击力  
> \- Flex布局实现垂直居中  
> \- 首行缩进符合中文排版习惯

动态标题效果：

```javascript
.zyx-title::after {
  content: '关于张艺兴';
  color: transparent;
  background: linear-gradient(to right, #f3e5f5, #6a1b9a);
  background-clip: text;
  clip-path: circle(100px at 100% 50%);
  animation: move1 5s linear infinite;
}
```

> 动画效果 ：
> 
> \- 渐变文字色彩  
> \- 圆形裁剪路径动画  
> \- 5秒循环动画
