---### 写给每个被var/let/const搞懵的新手

> **一句话总结**：
> 
> 1️⃣ **能用const就用const**（不变化的量）
> 
> 2️⃣ **需要变化就用let**（会变化的量）
> 
> 3️⃣ **永远不要用var**（容易出问题的老古董）

### 一、var有什么问题？举个🌰你就懂

#### 场景1：变量乱跑 (作用域问题)

```javascript
// 用var声明
function testVar() {
  if (true) {
    var a = "我在if里面";
  }
  console.log(a); // 居然能输出！变量跑到if外面了
}

// 用let声明
function testLet() {
  if (true) {
    let b = "我在if里面";
  }
  console.log(b); // 报错！这才是正常逻辑
}
```

**比喻**：

*   `var`像没关门的房间，谁都能进
*   `let/const`像装了密码锁的房间，只在当前区域有效

#### 场景2：循环陷阱

```javascript
// 用var的坑爹循环
for (var i = 0; i < 3; i++) {
  setTimeout(() => {
    console.log(i); // 输出3次3！
  }, 100);
}

// 用let的正确示范
for (let j = 0; j < 3; j++) {
  setTimeout(() => {
    console.log(j); // 正确输出0,1,2
  }, 100);
}
```

**为什么**：

*   `var`会把变量提到全局，所有循环共用同一个i
*   `let`每次循环都创建一个新变量j

### 二、const不是常量吗？怎么还能改？

#### 正确理解const

```javascript
// 基本类型：真的不能改
const PI = 3.14;
PI = 3.1415; // 报错！

// 引用类型：改内容可以，换对象不行
const person = { name: '小明' };
person.age = 18; // ✅ 可以加属性
person = { name: '小红' }; // ❌ 报错！
```

**记忆口诀**：

*   const锁的是**变量名**，不是**变量值**
*   就像你家的门牌号不变，但屋里家具可以换

### 三、什么时候用哪个？超简单决策树

#### 1️⃣ **先用const**：适用于90%的情况

*   配置信息
*   导入模块
*   函数表达式

```javascript
const API_URL = 'https://api.example.com'; // 配置
const sayHi = () => console.log('你好'); // 函数
```

#### 2️⃣ **改用let**：需要变化的值

*   循环计数器
*   状态标记
*   需要重新赋值

```javascript
let loading = true; // 状态标记
loading = false; 

for (let i = 0; i < 5; i++) { // 循环计数器
  // ...
}
```

#### 3️⃣ **永远不用var**：除非你在写古董代码

### 四、常见问题QA

#### Q1：用了const还能修改对象属性，这不是bug吗？

**不是bug！这是设计特性**

*   const只防止**重新赋值**，不限制**修改已有内容**
*   如果需要完全冻结对象，可以用：

```javascript
const obj = Object.freeze({ a: 1 });
obj.a = 2; // 静默失败（严格模式会报错）
```

#### Q2：为什么说let解决了循环问题？

**看这个对比**：

```javascript
// var写法（错误）
var funcs = [];
for (var i = 0; i < 3; i++) {
  funcs.push(function() { console.log(i) });
}
funcs[0](); // 3（所有函数共享同一个i）

// let写法（正确）
let funcs = [];
for (let j = 0; j < 3; j++) {
  funcs.push(function() { console.log(j) });
}
funcs[0](); // 0（每个j都是独立副本）
```

#### Q3：团队协作时怎么保持规范？

**配置ESLint规则**（自动检查工具）：

```javascript
{
  "rules": {
    "no-var": "error",         // 禁用var
    "prefer-const": "error"    // 优先用const
  }
}
```

### 实战练习：找出代码中的问题

```javascript
// 问题代码
var count = 0;
function add() {
  var result = count + 1;
  return result;
}

for (var i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 100);
}

const user = { name: '张三' };
user = { name: '李四' };
```

**答案**：

1.  所有var换成const/let
2.  循环中的var i要改成let
3.  最后的user重新赋值违反const规则

记住这些原则，你的JavaScript代码质量立刻提升一个档次！
