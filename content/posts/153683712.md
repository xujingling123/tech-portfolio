---### 1\. HTML布局结构分析

```html
<section class="future-tech py-5" id="section3">
  <div class="container py-5 position-relative">
    <!-- 标题区域 -->
    <h2 class="text-center fw-bold display-4">影视作品</h2>
    <p class="text-center fs-6 mt-3 info">描述文字...</p>
    
    <!-- 网格布局容器 -->
    <div class="row mt-5">
      <div class="box">
        <ul>
          <li class="item"><p>不说话的爱</p></li>
          <li class="item"><p>孤注一掷</p></li>
          <li class="item"><p>扫黑风暴</p></li>
          <li class="item"><p>传说</p></li>
        </ul>
      </div>
    </div>
  </div>
</section>
```

> 技术特点：
> 
> \- 使用语义化HTML5标签 <section> 定义内容区块  
> \- 通过 position-relative 为背景叠加效果做准备  
> \- 简洁的列表结构实现四部影视作品的展示

### 2\. CSS 卡片折叠效果实现

原始Grid布局：

```javascript
.future-tech .box ul {
  display: grid;
  grid-template-columns: 2fr 1fr 1fr 1fr;  /* 2:1:1:1比例布局 */
  grid-template-rows: 527px;               /* 固定高度 */
  gap: 8px;                               /* 网格间距 */
  transition: all .5s;                    /* 平滑过渡动画 */
}
```

> \- 2fr 1fr 1fr 1fr ：第一个项目占据2份空间，其余各占1份  
> \- 固定高度527px ：确保视觉一致性  
> \- 8px间距 ：适当的呼吸空间避免拥挤感

背景图片与遮罩效果：

```javascript
.future-tech {
  position: relative;
  background: url(../img/bg1.avif) no-repeat;
  background-position: center;
  background-size: cover;
  background-attachment: fixed;  /* 视差滚动效果 */
}

.future-tech::before {
  content: '';
  position: absolute;
  width: 100%;
  height: 100%;
  background: rgba(18, 18, 18, 0.9);  /* 深色半透明遮罩 */
}
```

> \- 固定背景 ： background-attachment: fixed 创造视差滚动效果  
> \- 遮罩层 ：使用伪元素叠加深色半透明层，增强文字可读性  
> \- 响应式背景 ： cover 属性确保背景图片自适应容器

CSS:has() 选择器动态布局

```javascript
/* 鼠标经过第一个项目时，调整网格比例 */
.future-tech .box ul:has(.item:nth-child(1):hover) {
  grid-template-columns: 2fr 1fr 1fr 1fr;
}

/* 鼠标经过第二个项目时 */
.future-tech .box ul:has(.item:nth-child(2):hover) {
  grid-template-columns: 1fr 2fr 1fr 1fr;
}

/* 鼠标经过第三个项目时 */
.future-tech .box ul:has(.item:nth-child(3):hover) {
  grid-template-columns: 1fr 1fr 2fr 1fr;
}

/* 鼠标经过第四个项目时 */
.future-tech .box ul:has(.item:nth-child(4):hover) {
  grid-template-columns: 1fr 1fr 1fr 2fr;
}
```

> has()选择器原理：
> 
> \- 父元素选择 ：根据子元素的状态改变父元素样式  
> \- 动态响应 ：鼠标悬停时自动调整网格比例  
> \- 平滑过渡 ：配合 transition: all .5s 实现流畅动画

项目样式与交互效果：

```javascript
.future-tech .box .item {
  position: relative;
  background: url(/img/zyx-act4.jpg) no-repeat 50%/cover;
}

.future-tech .box .item:nth-child(2) {
  background-image: url(/img/zyx-act3.jpg);
}
/* ... 其他项目的背景图片设置 */
```

文字悬浮效果：

```javascript
.future-tech .box .item p {
  position: absolute;
  left: 0;
  bottom: -10px;        /* 初始位置在容器外 */
  opacity: 0;           /* 初始透明 */
  transition: all .5s;  /* 平滑过渡 */
}

.future-tech .box .item:hover p {
  background: rgba(0, 0, 0, 0.5);  /* 半透明背景 */
  bottom: 0;                        /* 移动到容器底部 */
  opacity: 1;                       /* 完全显示 */
  width: 100%;                      /* 全宽显示 */
}
```
