---#### **1\. 弱网测试与流量控制**

*   **Charles限速配置**： `Proxy → Throttle Settings → 设置带宽（100Kbps）、延迟（500ms）、丢包率（20%）`
*   **Linux TC命令详解**：
    
    ```bash
    # 添加延迟和丢包  
    tc qdisc add dev eth0 root netem delay 200ms loss 15%  
    # 清除规则  
    tc qdisc del dev eth0 root
    ```
    

#### **2\. 断网与重连测试方案**

*   **Android ADB模拟断网**：
    
    ```bash
    adb shell svc wifi disable    # 关闭Wi-Fi  
    adb shell svc data disable    # 关闭移动数据  
    ```
    
*   **自动化测试框架集成**： Appium + Selenium模拟网络切换（Wi-Fi → 4G）。
