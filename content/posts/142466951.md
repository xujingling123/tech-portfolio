---### 描述

给定一个长度为 n 的数组 num 和滑动窗口的大小 size ，找出所有滑动窗口里数值的最大值。

例如，如果输入数组{2,3,4,2,6,2,5,1}及滑动窗口的大小3，那么一共存在6个滑动窗口，他们的最大值分别为{4,4,6,6,6,5}； 针对数组{2,3,4,2,6,2,5,1}的滑动窗口有以下6个： {\[2,3,4\],2,6,2,5,1}， {2,\[3,4,2\],6,2,5,1}， {2,3,\[4,2,6\],2,5,1}， {2,3,4,\[2,6,2\],5,1}， {2,3,4,2,\[6,2,5\],1}， {2,3,4,2,6,\[2,5,1\]}。

窗口大于数组长度或窗口长度为0的时候，返回空。

数据范围： 1≤n≤10000，0≤size≤10000，数组中每个元素的值满足 ∣val∣≤10000

要求：空间复杂度 O(n)，时间复杂度 O(n)

### 示例1

输入：

\[2,3,4,2,6,2,5,1\],3

返回值：

\[4,4,6,6,6,5\]

### 示例2

输入：

\[9,10,9,-7,-3,8,2,-6\],5

返回值：

\[10,10,9,8\]

### 示例3

输入：

\[1,2,3,4\],5

返回值：

\[\]

## 思路分析：

该题可以分两步来解决（暴力拆解）：

1.第一层循环是滑动窗口的个数，对应的num.length-size+1

2.第二层循环来求解每size个的temp数组的最大值，然后添加到re

## 代码：

```java
import java.util.*;


public class Solution {
    public int getMax(int[] list){
        int max=list[0];
        for(int i=1;i<list.length;i++){
            if(list[i]>max){
                max=list[i];
            }
        }
        return max;
    }
    /**
     * 
     * @param num int整型一维数组 
     * @param size int整型 
     * @return int整型ArrayList
     */
    public ArrayList<Integer> maxInWindows (int[] num, int size) {
        ArrayList<Integer> re=new ArrayList<>();
        int[] temp=new int[size];
        //特殊情况
        if(num.length<size|| size==0) return re;
        int flag=size;
        int len=num.length-size+1;
        for(int i=0;i<len;i++){
            for(int j=i;j<i+size;j++){
                temp[j-i]=num[j];
            }
            re.add(getMax(temp));
        }
        return re;
    }
}
```
