---题1：

设计一个算法delminnode(LinkList \*&L)，在带头结点的单链表L中删除所有结点值最小的结点（可能有多个结点值最小的结点）

```cpp
void delminnode(LinkList *&L)
{
	LinkList *pre=L,*p=pre->next;
	ElemType mindata=p->data;
	while (p!=NULL && p->data<mindata)
	{	mindata=p->data;
		p=p->next;
	}//先找到最小值
	p=pre->next;//从头开始

	while (p!=NULL)	//查找等于最小值的结点，找到则删除
	{
		if (p->data==mindata)
		{	pre->next=p->next;
			free(p);
		}
		pre=pre->next;
		p=pre->next;
	}
}
```

题2：

 假设二叉树采用二叉链存储结构存储，设计一个算法copy(BTNode \*b,BTNode \*&t)，由二叉树b复制成另一棵二叉树t。

```cpp
void copy(BTNode *b,BTNode *&t)
{
	BTNode *l,*r;
	if (b==NULL) t=NULL;
	else
	{
		t=(BTNode *)malloc(sizeof(BTNode));
		copy(b->lchild,l);
		copy(b->rchild,r);
		t->lchild=l;
		t->rchild=r;
	}
}
```
