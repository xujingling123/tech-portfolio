---在懒加载场景下，一下子拉到底部导致所有图片同时触发懒加载，可能会造成瞬间加载压力过大，影响页面性能。可以从以下几个方面避免这种情况：

*   **设置加载阈值**：使用 IntersectionObserver 时，设置合适的`rootMargin`和`threshold`属性。`rootMargin`用于扩大或缩小视口的检测范围，`threshold`定义元素与视口的相交比例。例如，将`rootMargin`设为`'0px 0px -200px 0px'`，意味着元素距离视口底部 200px 时就开始加载；`threshold`设为`[0, 0.2]`，表示元素开始进入视口和进入视口 20% 时都触发加载，通过这种方式可以控制图片加载的提前量和频率，避免全部图片同时加载。

```javascript
// 示例代码
const { stop } = useIntersectionObserver(
  el,
  ([{ isIntersecting }]) => {
    if (isIntersecting) {
      el.src = binding.value;
      stop();
    }
  },
  {
    root: null,
    rootMargin: '0px 0px -200px 0px',
    threshold: [0, 0.2]
  }
);
```

*   **限制并发加载数量**：可以通过计数器和队列控制同时加载的图片数量。声明一个计数器变量，记录当前正在加载的图片数量，设置最大并发加载数量（如`maxConcurrentLoad`为 3）。图片进入视口触发加载时，若计数器小于最大并发数，则允许加载并增加计数器；否则，将图片的加载任务加入队列。当有图片加载完成时，减少计数器，并从队列中取出下一个任务进行加载 。

```javascript
let loadCounter = 0;
const maxConcurrentLoad = 3;
const loadQueue = [];
const loadImage = (imgElement) => {
  if (loadCounter < maxConcurrentLoad) {
    loadCounter++;
    imgElement.src = imgElement.dataset.src;
    imgElement.onload = () => {
      loadCounter--;
      if (loadQueue.length > 0) {
        const nextImg = loadQueue.shift();
        loadImage(nextImg);
      }
    };
  } else {
    loadQueue.push(imgElement);
  }
};
```

*   **节流与防抖**：采用节流或防抖技术，限制触发懒加载的频率。节流函数能确保在一定时间间隔内，只允许执行一次加载操作；防抖函数则是在触发事件后，等待一定时间，若期间未再次触发，则执行加载操作，若再次触发则重新计时。例如使用节流函数，设置每隔 200 毫秒允许加载一张图片，避免短时间内大量加载请求。

```javascript
// 节流函数示例
function throttle(func, delay) {
  let timer = null;
  return function() {
    if (!timer) {
      func.apply(this, arguments);
      timer = setTimeout(() => {
        timer = null;
      }, delay);
    }
  };
}
const throttledLoad = throttle((imgElement) => {
  imgElement.src = imgElement.dataset.src;
}, 200);
```

*   **分页加载**：结合分页技术，每次只加载当前页的数据和图片。当用户滚动到页面底部时，再加载下一页的数据和图片。这样可以减少一次性加载的图片数量，同时提升用户体验，避免大量图片同时加载带来的性能问题。 例如在电商商品列表中，每页展示 20 个商品图片，用户滚动到底部时加载下 20 个商品图片。
