![](https://i-blog.csdnimg.cn/blog_migrate/12f10a9da11d9c8794547b08cf5bfe81.png)

![](https://i-blog.csdnimg.cn/blog_migrate/4d40951de4799186ab750b1790eb1aa2.png) 

代码：

main函数里面的：

    int a = 7;  
    int b = 19;  
    printf("交换前的数字：%d  %d\\n", a, b);  
    swap(&a, &b);  
    printf("交换后的数字：%d  %d\\n", a, b);

函数：

void swap(int\* i, int\* j) {  
    int t = 0;  
    t = \*i;  
    \*i = \*j;  
    \*j = t;  
}
