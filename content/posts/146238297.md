#### **2\. HTTP协议深度剖析**

*   **请求/响应结构**：
    
    ```bash
    GET /index.html HTTP/1.1  
    Host: www.example.com  
    User-Agent: Mozilla/5.0  
    
    HTTP/1.1 200 OK  
    Content-Type: text/html  
    <html>...</html>
    ```
    
*   **关键面试题**：
    *   _HTTP长连接（Keep-Alive）如何提升性能？_
        *   复用TCP连接，减少握手次数，降低延迟。
    *   _Cookie与Session的区别？_
        *   Cookie存储在客户端，Session存储在服务端，通过SessionID关联。

#### **3\. HTTPS安全机制全流程**

*   **TLS握手过程图解**：
    1.  ClientHello → 2. ServerHello（含证书） → 3. 密钥交换 → 4. 加密通信
*   **实战：OpenSSL验证证书**：
    
    ```bash
    openssl s_client -connect example.com:443 -servername example.com
    ```
