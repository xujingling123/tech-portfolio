---首先要知道闰年是怎么计算的：

**1.能被4整除，且不能被100整除；**

**2.能被400整除。**

![](https://i-blog.csdnimg.cn/blog_migrate/1f982d2daaa60412f028433ff22b295b.png)

 ![](https://i-blog.csdnimg.cn/blog_migrate/2f4ac967b59b98af24d0c1a4e94b0c04.png)

代码：

//求1000-2000年之间的闰年  
int main() {  
    int count = 0;  
    for (int num = 1000; num <= 2000; num++) {  
        //判断num是不是闰年？1.能被4整除，且不能被100整除；2.能被400整除  
        if (((num % 4 == 0) && (num % 100 != 0)) || (num % 400 == 0)) {  
            count++;  
            printf("%d  ", num);

        }  
    }  
    printf("1000-2000年之间的闰年个数：%d\\n", count);  
    return 0;  
}

**注意：这里要特别注意括号的处理，if判断里面将两张情况都囊括在内，&&代表与，||代表或。**

**巧妙的使用&&和||可以让代码更加的简洁容易**
