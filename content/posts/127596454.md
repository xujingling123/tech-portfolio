这里我使用了flag的方法来巧妙的解决是正负号的问题

当然还有很多其他的方法也可以实现，比如用if条件语句，为i奇数时，为＋； i偶数时，为-

我就用了比较简单代码比较少的一种

函数代码：

double get\_result() {  
    int i = 0;  
    int flag = 1;  
    double sum = 0.0;  
    for (i = 1; i <= 100; i++) {  
        sum += flag\*1.0 / i;  
        flag = -flag;  
    }

    return sum;  
}
