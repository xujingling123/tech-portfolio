---### 一、项目概述

**1.整体架构**

这是一个基于 WebSocket 的实时客服聊天系统，采用 uni-app 框架开发，支持文本、表情和图片消息的发送与接收。

**2.核心组件**

WebSocket 连接管理 (`chat.ts`)

*   使用ChatWebSocket类封装 WebSocket 连接逻辑
*   实现了连接管理、消息发送、心跳机制等功能
*   通过单例模式导出 ChatWebSocket 实例供页面使用

聊天界面 (`large-cap-service.vue`)

*   实现完整的聊天界面，包括消息展示、输入区域、表情选择、图片发送等功能
*   通过 WebSocket 与服务端进行实时通信

### 二、实现流程

1.消息收发流程

**发送消息**:

*   用户输入文本/选择表情/发送图片
*   调用 `chatWebSocket.sendChatMessage()` 发送消息
*   消息先显示在本地列表，状态为"发送中"
*   收到服务端确认后更新状态为"已发送"

        if (this.isConnected || this.isConnecting) {

            return

        this.userId = uid
        this.isConnecting = true
        this.messageCallback = onMessage

        console.log(`开始连接聊天 WebSocket: ${url}`)
        this.socketTask = uni.connectSocket({

            success: (res: any) => {
                console.log('聊天 WebSocket 连接成功', res)
            },
            fail: (err: any) => {
