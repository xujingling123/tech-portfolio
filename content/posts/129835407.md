---代码：

```cpp
#include<stdio.h>
main()
{
	char ch;
	int n = 0, m = 0;
	printf("Input 字符串:");
	while ((ch = getchar()) != '\n')//依次判断输入字符的类型
	{
		if (ch <= '9' && ch >= '0')
			n++;
		else if ((ch <= 'Z' && ch >= 'A')||(ch <= 'z' && ch >= 'a'))
			m++;

	}
	printf("数字%d 字母%d \n", n, m);

}
```
