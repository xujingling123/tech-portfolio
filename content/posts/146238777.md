---#### **1\. TCP性能优化核心指标**

*   **三次握手性能瓶颈**：
    *   高并发场景下SYN队列溢出（`netstat -s | grep SYNs`）。
    *   解决方案：调整内核参数`net.ipv4.tcp_max_syn_backlog`。
*   **TCP Keep-Alive参数配置**：
    
    ```bash
    sysctl -w net.ipv4.tcp_keepalive_time=600 # 10分钟探测一次
    ```
    

#### **2\. CDN与负载均衡测试**

*   **验证CDN节点分发**：
    
    ```bash
    dig +short example.com          # 查看DNS解析结果  
    curl -I http://example.com      # 检查响应头中的CDN标识（如X-Cache）
    ```
    
*   **负载均衡策略测试**：
    *   轮询（Round Robin）、加权轮询（Weighted RR）、最少连接（Least Connections）。

#### **3\. Wireshark高阶抓包技巧**

*   **过滤重传包与丢包分析**：
    
    ```bash
    tcp.analysis.retransmission    # 过滤所有TCP重传包  
    tcp.analysis.lost_segment      # 显示丢失的数据段  
    ```
    
*   **RTT（往返时间）计算**： `Statistics → TCP Stream Graph → Round Trip Time Graph`
