---这里讲3种方法来实现求一个整数存储在内存中的二进制中1的个数，

方法一（只能是正整数）：

![](https://i-blog.csdnimg.cn/blog_migrate/6f6146e82e6e250f77252f2ba1303832.png)

结果：

 ![](https://i-blog.csdnimg.cn/blog_migrate/5272ab1d8d1b364f19b06cede01d92b1.png)

代码：

int main() {  
    int a = 3;  
    int count = 0;  
    int flag = 0;  
    while (a) {  
        flag = a & 1;  
        if (flag==1)  
        {  
            count++;  
        }  
        a = a >> 1;  
    }

    printf("%d\\n", count);  
    return 0;  
}

该方法如果是负数则不行，因为a为-1，二进制数是32个1，进行右移（算数右移：左边用原符号位填充，右边丢弃），这样a的二进制就一直是32个1，则while循环一直为真，陷入死循环！！

所以该方法只适用于正整数，负数还是有bug的

代码： 

int getnumone(int a) {  
    int count = 0;  
    int i = 0;  
    for (i = 0; i < 32; i++) {  
        //判断该数字是否为1  
        if (((a>>i) & 1) == 1) {  
            count++;  
        }  
    }  
    return count;  
}

int main() {  
    int a = 3;  
    int sum = getnumone(a);  
    printf("%d\\n", sum);  
    return 0;  
}

方法三（最优解）：

![](https://i-blog.csdnimg.cn/blog_migrate/b7f768ce8cdd9716ef477ce03bda0306.png)

 结果： 

![](https://i-blog.csdnimg.cn/blog_migrate/e35c84a910bfd9f57b3ab4cf8fe43752.png)

 代码：

int getnumCount(int a) {  
    int count = 0;  
    while (a) {  
        a = a & (a - 1);

        //a-1是让它向右移一位，a & (a - 1)判断下一位是否为1  
        //假设a=3  
        //0011  a  
        //0010 a-1  
        //0010 a = a & (a - 1)  
        //0001 a-1  
        //0000 a = a & (a - 1)  
        count++;  
    }  
    return count;  
}  
int main() {  
    int a = -1;  
    int sum=getnumCount(a);  
    printf("%d\\n", sum);  
    return 0;  
}

这三个方法除了第一个方法是不能计算负整数的二进制的1的个数，

后面两个方法都是可以计算所有整数的，方法3是最优解，效率比方法2高
