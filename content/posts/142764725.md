---`driver.find_element` 是 Selenium WebDriver 中用于在网页中查找单个元素的方法

#### 通过 ID 查找元素

1.先在浏览器确定输入框的id名：

![](https://i-blog.csdnimg.cn/direct/bce5e4c537364ece82b8ef2c54958177.png)

获取到id名为：kw

2.在pycharm里面编写代码：

```python
# 导包
from selenium import webdriver
from time import sleep
from selenium.webdriver.common.by import By

# 获取浏览器驱动
driver = webdriver.Chrome()
# 打开url
driver.get("http://www.baidu.com")

# 找到id属性名
search = driver.find_element(By.ID, "kw")
# 输入内容
search.send_keys("张艺兴")

# 暂停6秒
sleep(6)
# 关闭浏览器驱动
driver.quit()
```
