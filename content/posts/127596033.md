---首先要明白/和%的区别：

/ 是除，如果是整数相除，只取整数部分，没有四舍五入之类的。

% 是取模，即取除法的余数

其实在这个题目里面/就是判断十位上为9的个数，而%就是判断个位上为9的个数，当明白了这个点，这个题目就很简单了。

![](https://i-blog.csdnimg.cn/blog_migrate/9978e75f41107d329605eb572214b3b7.png)

 ![](https://i-blog.csdnimg.cn/blog_migrate/26c4e4e93bc25644af5358666dfa3d06.png)

函数代码：

int get\_nine\_count() {  
    int i = 0;  
    int count = 0;  
    for (i = 1; i <= 100; i++) {  
        if (i%10==9||i/10==9)  
        {  
            count++;  
        }  
    }  
    return count;  
}
