---### 项目概述与技术架构

”小羊咩咩“网站是一个使用纯CSS实现网页动态效果的现代化单页应用，展现了现代Web开发中CSS动画和交互设计的强大能力。

### 技术栈组成

\- 前端框架 ：Bootstrap 5.0  
\- 样式语言 ：CSS3（含CSS变量、动画、变换等）  
\- 布局技术 ：Flexbox + CSS Grid  
\- 响应式设计 ：媒体查询 + Bootstrap栅格系统  
\- 交互效果 ：CSS Hover动画 + 3D变换

### 设计理念

项目采用深色主题设计，以紫色系为主色调。整个网站强调视觉冲击力和交互体验，通过CSS动画实现流畅的用户体验。

#### 1\. 基础结构与依赖

轮播图核心依赖：

*   Bootstrap 5 CSS 框架（提供轮播组件基础样式）
*   Bootstrap 5 JS 文件（实现轮播交互逻辑，如切换、自动播放）
*   自定义 CSS（index.css中定义的主题适配样式）

#### 2\. 核心布局结构

```html
<section class="banner" id="banner">
  <!-- 轮播容器 -->
  <div id="carouselExampleCaptions" class="carousel slide" data-bs-ride="carousel">
    <!-- 轮播项容器 -->
    <div class="carousel-inner">
      <!-- 轮播项1（默认激活） -->
      <div class="carousel-item active">
        <img src="./img/banner1.jpg" class="d-block w-100" alt="...">
      </div>
      <!-- 轮播项2 -->
      <div class="carousel-item">
        <img src="./img/banner2.jpg" class="d-block w-100" alt="...">
      </div>
      <!-- 轮播项3 -->
      <div class="carousel-item">
        <img src="./img/banner3.jpg" class="d-block w-100" alt="...">
      </div>
    </div>
    <!-- 上一张按钮 -->
    <button class="carousel-control-prev" ...></button>
    <!-- 下一张按钮 -->
    <button class="carousel-control-next" ...></button>
  </div>
</section>
```

#### 3\. 关键类与属性解析

##### 容器类

*   `carousel`：轮播组件基础类，定义核心样式与布局
*   `carousel slide`：`slide`类添加切换时的平滑滑动动画
*   `data-bs-ride="carousel"`：自动初始化轮播并启用自动播放

##### 轮播项类

*   `carousel-inner`：包裹所有轮播项的容器
*   `carousel-item`：单个轮播项容器
*   `active`：标记当前激活的轮播项（必须为第一个轮播项添加，否则轮播不显示）
*   `d-block w-100`：强制图片为块级元素并占满宽度，避免默认 inline 元素的间隙问题

##### 控制按钮

*   `carousel-control-prev`/`carousel-control-next`：前后切换按钮样式
*   `data-bs-target="#carouselExampleCaptions"`：指定控制的轮播容器 ID
*   `data-bs-slide="prev"`/`data-bs-slide="next"`：定义切换方向

#### 4\. 自定义样式适配（来自 index.css）

##### 轮播容器样式

```javascript
.banner {
  width: 100vw; /* 占满屏幕宽度 */
  height: 50vw; /* 高度随宽度等比例变化（响应式） */
  /* 顶部渐变遮罩，使轮播图底部与页面内容过渡更自然 */
  mask-image: linear-gradient(rgb(0, 0, 0) 80%, rgba(0, 0, 0, 0) 100%);
  -webkit-mask-image: linear-gradient(rgb(0, 0, 0) 80%, rgba(0, 0, 0, 0) 100%);
}
```

##### 轮播图片样式

```javascript
.banner .carousel-item img {
  width: 100%;
  height: 100%;
  object-fit: cover; /* 图片自适应容器，保持比例不拉伸 */
  object-position: center; /* 图片居中显示 */
}
```

##### 响应式适配

在小屏幕设备上优化显示：

```javascript
/* 移动端隐藏轮播标题和指示器（若有） */
@media (max-width: 768px) {
  .carousel-caption,
  .carousel-indicators {
    display: none;
  }
}

/* 中等屏幕调整轮播位置 */
@media (max-width: 992px) {
  .banner {
    margin-top: 80px; /* 避免被固定导航栏遮挡 */
  }
}
```

#### 5\. 交互功能说明

*   **自动播放**：通过`data-bs-ride="carousel"`默认启用，轮播项会自动按顺序切换
*   **手动切换**：点击左右箭头按钮可切换上一张 / 下一张
*   **滑动切换**：在移动端支持触摸滑动切换轮播项
*   **动画效果**：轮播切换时的平滑过渡动画由`slide`类实现
