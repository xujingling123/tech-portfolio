---### 描述

对于一个长度为 n 字符串，我们需要对它做一些变形。

首先这个字符串中包含着一些空格，就像"Hello World"一样，然后我们要做的是把这个字符串中由空格隔开的单词反序，同时反转每个字符的大小写。

比如"Hello World"变形后就变成了"wORLD hELLO"。

数据范围: 1≤n≤106 , 字符串中包括大写英文字母、小写英文字母、空格。

进阶：空间复杂度 O(n)， 时间复杂度 O(n)

#### 输入描述：

给定一个字符串s以及它的长度n(1 ≤ n ≤ 10^6)

#### 返回值描述：

请返回变形后的字符串。题目保证给定的字符串均由大小写字母和空格构成。

### 示例1

输入：

"This is a sample",16

返回值：

"SAMPLE A IS tHIS"

### 示例2

输入：

"nowcoder",8

返回值：

"NOWCODER"

### 示例3

输入：

"iOS",3

返回值：

"Ios"

## 思路分析：

该题可以分为3个步骤：

1.先分割整个字符，使用split方法进行分割

2.对字符串的每个字符进行判断大小写，然后转换大小写

3.再根据分割出来的每个字符串，从末尾添加进里面，实现反转

## 代码：

```java
import java.util.*;


public class Solution {
    /**
     * 
     * @param s string字符串 
     * @param n int整型 
     * @return string字符串
     */
    public String trans (String s, int n) {
        String[] word=s.split(" ",-1);
        StringBuilder str=new StringBuilder();
        for(int i=word.length-1;i>=0;i--){
            str.append(Upto(word[i]));
            if(i==0) break;
            str.append(" ");
            
        }
        return str.toString();


    }

    public String Upto(String s){
        StringBuilder strb=new StringBuilder();
            for(char c:s.toCharArray()){
                if(Character.isLowerCase(c)){
                    strb.append(Character.toUpperCase(c));
                    continue;
                }
                if(Character.isUpperCase(c)){
                    strb.append(Character.toLowerCase(c));
                    continue;
                }
            }
            return strb.toString();

    }
}
```
