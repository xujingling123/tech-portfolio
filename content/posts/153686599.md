### 2.3D翻转盒子效果实现

基础样式设置：

```css
.footer {
  background-color: #0a0a0a;  /* 深黑色背景 */
  padding-top: 80px;         /* 顶部内边距 */
}
```

标题样式设计：

```css
.footer dt {
  position: relative;
  font-size: 1.2rem;
  font-weight: 600;
  padding-bottom: 10px;
  margin-bottom: 15px;
}

.footer .logo-title {
  font-size: 2.8rem;         /* 品牌标题更大 */
  color: var(--lay-purple);  /* 使用紫色主题色 */
}

/* 标题下划线效果 */
.footer dt::after {
  content: '';
  position: absolute;
  left: 0;
  bottom: 0;
  width: 40px;
  height: 2px;
  background: linear-gradient(90deg, var(--lay-cyan), var(--lay-blue));
}
```

链接交互效果：

```css
.footer dd>a {
  display: block;                    /* 块级显示 */
  color: rgba(255, 255, 255, 0.7);  /* 半透明白色 */
  font-size: 1.1rem;
  text-decoration: none;
  transition: all 0.3s;             /* 平滑过渡 */
  margin-bottom: 15px;
}

.footer dd>a:hover {
  color: var(--lay-cyan);           /* 悬停变青色 */
  transform: translateX(5px);      /* 向右平移5px */
}
```

3D翻转动画技术：

```css
.footer .icons {
  position: relative;
  width: 100px;
  height: 300px;  /* 固定高度容纳6个图标 */
}

.footer .icons ul {
  position: absolute;
  width: 100px;
  height: 300px;
  list-style: none;
  gap: 5px;       /* 图标间距 */
}
```

```css
.footer .icons ul li {
  position: relative;
  width: 80px;
  height: 40px;
  margin-bottom: 15px;
  transform-style: preserve-3d;  /* 开启3D空间 */
  transition: all .5s;           /* 0.5秒过渡动画 */
}

/* 前后两面基础样式 */
.footer .icons ul li span {
  position: absolute;
  display: block;
  width: 100%;
  height: 100%;
  line-height: 40px;  /* 垂直居中 */
  font-size: 16px;
  text-align: center;
}

/* 正面样式 */
.footer .icons ul li .front {
  background: #fff;
  color: var(--lay-blue);
  transform: translateZ(20px);  /* 向前平移20px */
}

/* 底面样式 */
.footer .icons ul li .bottom {
  background: var(--lay-purple);
  color: #fff;
  transform: translateY(20px) rotateX(-90deg);  /* 向下平移并旋转 */
}

/* 悬停翻转效果 */
.footer .icons ul li:hover {
  transform: rotateX(90deg);  /* 绕X轴旋转90度 */
}
```

> \- transform-style: preserve-3d ：创建3D变换空间  
> \- translateZ() ：实现Z轴深度效果  
> \- rotateX() ：X轴旋转实现翻转动画  
> \- transition ：平滑的0.5秒过渡效果

文字显示动画：

```css
.footer .icons ul li p {
  opacity: 0;  /* 默认隐藏文字 */
}

/* 悬停时显示对应文字 */
.footer .icons ul li:hover .show-text1,
.footer .icons ul li:hover .show-text2,
.footer .icons ul li:hover .show-text3,
.footer .icons ul li:hover .show-text4,
.footer .icons ul li:hover .show-text5,
.footer .icons ul li:hover .show-text6 {
  transform: translateX(90px) rotateX(-90deg);
  opacity: 1;  /* 显示文字 */
}
```

文字显示机制 ：利用CSS选择器精确控制每个图标对应的文字显示，实现一对一的关联效果

### 3.侧边栏滑动条实现

```css
/* 滚动条整体宽度 */
::-webkit-scrollbar {
  width: 10px;  /* 滚动条宽度 */
}

/* 滚动条轨道样式 */
::-webkit-scrollbar-track {
  background: var(--lay-dark);  /* 深色背景 */
}

/* 滚动条滑块样式 */
::-webkit-scrollbar-thumb {
  background: linear-gradient(var(--lay-blue), var(--lay-cyan));
  border-radius: 10px;  /* 圆角设计 */
}

/* 鼠标悬停效果 */
::-webkit-scrollbar-thumb:hover {
  background: linear-gradient(var(--lay-cyan), var(--lay-blue));
}
```

滚动条定制 ：使用Webkit私有前缀实现跨浏览器的自定义滚动条样式。
