### 三、配置环境

#### 1\. 打开环境变量设置

*   `Win + R` → 输入 `sysdm.cpl` → 回车
*   点击「高级」→「环境变量」

![](https://i-blog.csdnimg.cn/direct/3ca569d9b4d64460b155fe16a84d06c7.png)

#### 2\. 新建系统变量

变量名

变量值

`JAVA_HOME`

`D:\Program Files\Java\jdk-17.0.1`（根据实际路径修改）

#### ![](https://i-blog.csdnimg.cn/direct/9c73489d082440f8ba67f01e0d3e5695.png)

#### 3\. 修改 `Path` 变量

在 `Path` 中添加：

```bash
%JAVA_HOME%\bin
```

![](https://i-blog.csdnimg.cn/direct/ec832aeb94a444bfb9426d4204a6b8f0.png)

### 四、验证安装是否成功

打开 **命令提示符（cmd）** 或 **终端（Terminal）**，输入：

```
java -version
```

![](https://i-blog.csdnimg.cn/direct/12bdfe711fb342258d9f32f898c15869.png)

再输入

```bash
javac -version
```

![](https://i-blog.csdnimg.cn/direct/df6492b41d084b58a514aad40302d3fc.png)

出现上述则是安装成功
